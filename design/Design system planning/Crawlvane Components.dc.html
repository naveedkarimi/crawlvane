  • Bands: 90–100 Good, 50–89 Needs work, 0–49 Poor. The number, a word and an icon always appear together.
  • Ring and bar fills use the status "solid" colours, which pass 3:1 against the track and the page. Brand Mint never shows a score.

  • The loading state shows a grey track and a "–" with "Checking" text. Never show a placeholder number.
