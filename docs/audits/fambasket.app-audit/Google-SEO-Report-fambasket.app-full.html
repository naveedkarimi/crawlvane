2. Audit Categories

2.1 Technical SEO

Score: 55/100

What Works

  • HTTPS and HSTS
  • Canonical and sitemap directives
  • Security headers

Findings

Inconsistent canonical-origin access High

A prescribed crawler request and intermittent direct requests received LiteSpeed 403, while a browser-compatible session received 200 application HTML.

Recommendation: Review WAF/LiteSpeed rules and verify stable 200 delivery for users and approved crawlers.

Sitemap has one URL Medium

The valid sitemap contains only the homepage.

Recommendation: Add all intended indexable public URLs and validate their status.

2.2 Content Quality

Score: 86/100

What Works

Findings

Claims need supporting proof Medium

2.4 Schema / Structured Data

Score: 92/100

What Works

  • Organization, WebSite, SoftwareApplication, Offer, and FAQPage markup
  • Stable @id relationships
  • FAQ parity with visible content

Findings

Schema image URL mismatch High

SoftwareApplication schema references hero-light.png while the rendered page uses hero-light.webp.

Recommendation: Use an existing canonical asset or publish the referenced image.

2.5 Performance (CWV)

Score: 75/100

What Works

  • Explicit image dimensions
  • Lazy loading below fold
  • Responsive visual layout

Findings

Field and lab CWV unavailable Medium

No Google credentials were configured and the crawler renderer was denied.

Recommendation: Run Lighthouse/PageSpeed against the stable canonical response and optimize based on LCP, INP, and CLS.
